# Pilotstudie

Prä-/Post-Design ohne Kontrollgruppe, N = 11 volljährige Teilnehmende, durchgeführt im November 2026
als Online-Befragung (Google Forms). Details zu Stichprobe, Ablauf und Ergebnissen: Abschnitt „Evaluation“ im Paper.

## Inhalt

| Datei | Inhalt |
| --- | --- |
| `materialien/fragebogen.pdf` | vollständiger Fragebogen (Druckansicht von Google Forms) |
| `materialien/fragebogen_mit_loesungen.pdf` | Fragebogen mit markierten richtigen Antworten |
| `materialien/einwilligung.md` | Wortlaut von Studieninformation und Einwilligung |
| `materialien/ablauf.md` | Ablauf und Instruktionen |
| `materialien/loesungen.md` | Lösungen der sieben Wissensfragen mit Zuordnung zu LZ1–LZ3 |
| `daten/pilotstudie_rohdaten_export.xlsx` | unveränderter Export aller Antworten |
| `daten/pilotstudie_rohdaten.csv` | dieselben Daten als CSV |
| `daten/codebuch.md` | Bedeutung und Kodierung der Spalten |
| `auswertung/auswertung.py` | Auswertungsskript |
| `auswertung/loesungsschluessel.json` | Wortlaut der richtigen Antworten für das Skript |
| `auswertung/ergebnisse.md` | Ausgabe des Skripts |

## Datenschutz

Die Daten enthalten keine Namen oder E-Mail-Adressen. Alle Teilnehmenden haben der anonymen Auswertung zugestimmt.
